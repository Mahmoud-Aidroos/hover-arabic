Before you enable translation

Automatic hover translation sends the English words you hover over, or text you select, to MyMemory (default) or Azure if configured. The provider receives your IP address. MyMemory receives text in the request URL and your contact email if you add one. Azure receives text and your personal API key.

Your PDF stays on this device. An arXiv link is downloaded directly from arXiv. No page URL or surrounding paragraph is sent to the translation provider. You can pause translation or restrict sites in Chrome.

Read the privacy policy

Translation stays paused until you choose to enable it. Enabling is optional; you can close this window.

On an arXiv PDF tab, use “Translate this arXiv PDF” to open it with hover translation. For other PDFs, choose a saved file in the reader.

Hovered words and selected English text are sent automatically to your chosen provider. No page URL or surrounding text is sent. Editable fields are skipped.

Leave blank to use anonymously. If supplied, your email is sent to MyMemory with each uncached lookup. Usage limits apply.

Create a Translator resource with the F0 free tier in Azure, then copy its key and location from “Keys and Endpoint.” Regional resources need the region. See README for full instructions.

Credentials stay on this device in Chrome extension storage; they are not encrypted or synced. Use a personal key, never a shared secret in a distributed copy.

Online-result cache: up to 500 entries, 24-hour expiry, kept in memory for this browser session. No bundled dictionary. Provider changes clear the cache.
