# Hover Arabic 2.3.0

English-to-Arabic translation when you hover over a word or select a short phrase, with right-to-left popups and session caching.

- Websites and the included PDF reader.
- Direct opening of arXiv PDFs from a link or the active paper tab.
- Free no-key MyMemory by default; optional Azure Translator with your own credentials.
- First-use explanation and affirmative enable choice before automatic transmission.
- Local PDF rendering; no full-document upload to the translation provider.
- Public privacy policy, project icons and support contact.

Requires Chrome 140+. Scanned PDFs need OCR, which is not included. PDF hover runs in the extension reader, not Chrome's built-in PDF viewer. Internet access and provider quotas apply; no offline dictionary is included.

Manual installation: download `hover-arabic-v2.3.0.zip`, extract it, open `chrome://extensions`, enable Developer mode, click Load unpacked and select the extracted `hover-arabic` folder. Click the extension icon, read the privacy notice and choose Enable automatic translation. Keep the extracted folder in place.
